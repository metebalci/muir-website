01 / WHAT IT IS

One system,
for two machines.

THE SYSTEMFROM MIT’S SOURCES

The Lisp Machine system

For both machines, continuing where MIT’s released system left off: MIT’s own sources, recovered from its backup tapes and brought up by LM-3.

THE MACHINEQUUX

QUUX is the CADR evolved

In QUUX, run by muir-sim and muir-fpga: better in performance and capacity, and in modern computing, such as the display’s resolution, block storage and the network. It says which improvements it has, and the system reads them at boot.

THE AIMEVOLUTION

It evolves the system

It changes the system where a change pays for itself, rather than rewriting it. Backward compatibility is not an aim.

THE RELEASESQUUX · THE CADR

Releases for both machines

Each a disk ready to boot, and the sources: QUUX’s made from the repository’s main branch, the CADR’s from its cadr branch. QUUX’s system in development is published too, rebuilt as it changes. The release notes say what each changed; get them on GitHub.

IT RUNS ONSIMULATOR · FPGA

muir-sim and muir-fpga

muir-sim, the simulator, and muir-fpga, on an FPGA, with ozd, the CADR’s associated machine, serving the CADR’s bands.
