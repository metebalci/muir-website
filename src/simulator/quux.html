03

QUUX’s system.

tools/fetch-system-for-quux.sh

QUUX is the CADR evolved, and quux runs it, with its own boot PROM, the video controller and block-disk. It needs muir-sys’s updated microcode and system on a raw image or a VHD with a GPT partition table: MIT’s own will not run on it. The script fetches the QUUX release System 2001, and checks every file against its SHA-256 sum. It puts the machine’s disk in vendor/run/ and makes the machine’s host folder beside it: QUUX reads its files from there through a device of its own, so it needs no file server.

04

Run it.

target/release/quux --micro --disk-pack vendor/run/release-2001-disk.vhd \
    --file-root vendor/run/release-2001-root

quux on the fast engine, micro; without --micro it runs rtl, at the machine’s own speed. On the rtl engine its cache and main memory are timed as an FPGA board’s. It prints where its screen is: point any VNC viewer there. It boots to a Lisp Listener, System 2001; (login "LISPM" "HOST" t) logs in.

02 / ITS OWN FLAGS

What quux
alone takes.

cadr refuses each of these. The manual gives the whole of each.

FlagWhat it gives
--disk-pack <image>Its disk, block-disk’s: a raw image or a VHD, with a GPT partition table. QUUX’s disk needs no tool of muir-sim’s: it is made with standard tools.
--file-root [<name>=]<folder>[,ro]The host folders its file device serves under the pathname host HOST.
--main-memory-size <n>MWMain memory, in whole megawords, 1MW to 64MW; 32MW by default.
--cache <words>The memory cache’s size, a power of two, on rtl.
--memory-timing <read>,<write>Main memory’s timing on the memory port, in ns, or a board’s own figures.
--tlb <entries>The TLB’s entries, a power of two from 1,024 to 32,768.
--video-size <width>x<height>The screen’s size, at most 1920 by 1080.
--rtc <unix-seconds>|hostThe real-time clock: the host’s clock, or a start that counts the machine’s own time.
--prom <file>The boot PROM to run.
--ethernet-socket <path>[,clocked]What sits behind the Ethernet device: a UNIX stream socket muir connects to, one Ethernet frame a record.
--ethernet-mac, --ip-address, --ip-gatewayThe Ethernet device’s MAC address, and the machine’s IPv4 address and gateway, which the system reads when its network starts.
--ethernet-traceEvery Ethernet frame the device sends and receives, to stderr.

03 / ITS NETWORK

A tap
on the host.

QUUX’s Ethernet link runs over a tap, the host’s end of a machine’s link. tools/quux-taps, run once as root, installs a pool of them, quux0 up, each with its own address and owned by one user, and makes them again at every boot; after that the user opens a tap with no privilege at all.

tools/ethernet-frame-mover puts a machine behind a tap: it takes a free tap of the pool and listens at a UNIX stream socket, which --ethernet-socket connects to, and prints the tap and the two flags to give quux for it. For quux0 they are muir’s defaults, so the first machine needs no flags at all.
