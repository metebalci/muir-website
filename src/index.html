Project
Muir.

A project about MIT’s CADR Lisp Machine, with three aims.

  1. Simulate the CADR accurately: in software (muir-sim’s cadr) and in hardware (muir-fpga’s CADR), from MIT’s schematics and sources, running MIT’s system and muir-sys’s 1xxx releases for the CADR.

    TODAY muir-sim boots MIT’s last release, System 100, on three engines down to every chip, and passes its test of two machines debugging each other. muir-fpga puts the CADR in the fabric of the Arty Z7-20, the Cora Z7-07S and the DE25-Nano.

  2. Evolve it into QUUX, a modern design, again in software (muir-sim’s quux) and in hardware (muir-fpga’s QUUX), running the updated system (muir-sys’s 2xxx releases for QUUX).

    TODAY QUUX boots the updated system in muir-sim, and muir-fpga puts QUUX in the fabric of the Arty Z7-20 and the DE25-Nano, where it runs the same system.

  3. Build it with AI: the Rust, the SystemVerilog, the Lisp changes and the FPGA work are written by Claude, through Claude Code; MIT’s own sources stay MIT’s.

The original,

Two purposes, on one base.

THE MIT ORIGINALAROUND 1978

CADR↙

The original, down to its chips.

MIT’s machine as it was built. Its simulation follows the original board schematics and runs the historical microcode and Lisp software; it is the reference every change in QUUX is measured against.

  • MIT’s processor, buses and peripheral boards
  • MIT’s original microcode and released system
  • Three simulation engines, down to chip level
  • 2,016 parts with one memory board and both displays

THE CADR, EVOLVED2026

QUUX↗

The CADR, changed step by step.

QUUX keeps the CADR’s microinstruction and its way of running Lisp, and rebuilds the processor, its memory and its devices where a change pays for itself.

  • 16K-word PDL buffer and a larger memory map
  • Multiply and divide in one instruction each
  • A 40 ns microcycle, and main memory behind a cache
  • The video controller, block-disk, a file device
  • muir-sys’s updated microcode and system

QUUX is still being developed: its hardware revisions, microcode and system change, and a later QUUX need not run today’s bands or microcode.

02 / ONE REPOSITORY EACH

Three projects.

Each is a repository of its own, with its own history and releases.
They share their flags, and the words they use.

SIMULATORRUST

muir-sim

The CADR and QUUX, simulated.

MIT’s CADR simulated from MIT’s own schematics of its boards, at three levels of detail down to every chip, booting MIT’s released system; and QUUX beside it. Two executables: cadr and quux.

The CADR finds its files, the time and its host table on ozd, over the Chaosnet; QUUX does not need it.

FPGASYSTEMVERILOG

muir-fpga

The machines in the fabric of FPGA boards.

muir-sim’s RTL model of the CADR in the fabric of small FPGA boards, held to muir-sim tick for tick: the Arty Z7-20, the Cora Z7-07S and the DE25-Nano. The same fabric is built as QUUX too, and runs on the Arty Z7-20 and the DE25-Nano.

A CADR board gets its files, the time and its host table from ozd, over the Chaosnet.

03 / MIT, AROUND 1978

The shared
origin.

A screen. A keyboard. A mouse. A network.
And Lisp, all the way down.

Around 1978, Tom Knight, David Moon, Jack Holloway and Guy Steele designed a workstation at the MIT AI Lab for a single person. The windows, the editor, the network code: the system was written in Lisp.

MIT built about thirty CADRs. They became the foundation for the first Lisp Machines sold by LMI and Symbolics. muir-sim simulates that machine, running MIT’s last release of its system, restored from recovered tapes; muir-fpga puts it in the fabric of an FPGA.

04 / ABOUT

Almost nothing here
is a first-hand invention.

The CADR, its schematics, wire lists, microcode and system are MIT’s, recovered by other people’s work over decades; muir-sim’s manual lists every source and what each contributed.

The projects are written with Claude Code, on Anthropic’s models; each project’s own page says how it was made. The site is designed with Codex, using OpenAI’s GPT Astra, and with Claude Code, using Anthropic’s Claude Opus.

Muir is named for Nathan Muir, the character Robert Redford plays in Spy Game (2001). In memory of Robert Redford.
