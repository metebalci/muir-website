THE MACHINES · THE CADR, MIT’S LISP MACHINE

CADR

The CADR is a 32-bit microcoded processor built at the MIT Artificial Intelligence Laboratory around 1978, and published as AI Memo 528 in 1980.

It is the machine the Lisp Machine system was written for. The drawings below are read from MIT’s own files; what each one shows, and every source, is in muir-fpga’s docs/cadr.md.

01 / A LISP MACHINE

Built at MIT
to run Lisp.

A screen, a keyboard, a mouse and a network.
And the system on it all written in Lisp.

The CADR is a computer built at the MIT AI Lab to run Lisp. It was one person’s workstation: a screen, a keyboard, a mouse and a network, and the system on it — the windows, the editor, the network code — was all written in Lisp.

Tom Knight, David Moon, Jack Holloway and Guy Steele drew it in about 1978. MIT built about thirty of them, and the first Lisp Machines LMI and Symbolics sold were built on it.

MIT’s schematics, wire lists, microcode and software for it survive. muir-sim simulates it from them, and muir-fpga puts it in the fabric of FPGA boards.

14 / FROM MIT’S CAD FILES

Seven netlists.

Each board as a netlist: every chip on it and every wire between them, read out of MIT’s own CAD files. They are what muir-sim’s chip engine simulates.

2,016parts.

Parts in a whole machine — one memory board on the Xbus and both display boards, the SIMPLE TV and the color TV, and 7,224 with all thirty-two memory boards.

Not drawn by hand. Pulled out of MIT’s own CAD files, then held pin for pin to MIT’s wire list for the same board.

15 / RUNNING IT

In software,
and in fabric.

muir-sim runs the CADR as cadr, on three engines down to every chip, and boots MIT’s System 100 on it: build and boot. muir-fpga puts it in the fabric of the Arty Z7-20, the Cora Z7-07S and the DE25-Nano. Either one gets its files and the time from ozd, its associated machine, over the Chaosnet.
