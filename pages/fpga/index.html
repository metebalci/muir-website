01 / WHAT IT IS

A CADR
in the fabric.

muir-fpga puts QUUX and the CADR in the fabric of an FPGA. The CADR is the Lisp Machine MIT designed around 1978, and muir-fpga’s CADR is muir-sim’s RTL model of it, synthesized into the fabric of an FPGA — the two processor boards, the bus interface, the disk controller, the display and the I/O board.

Its clock edges are close to the CADR’s but not identical. The CADR placed them with delay lines, and the FPGA can place them only on the ticks of one 10 ns clock, so some fall up to 7 ns later. The timing, instant by instant.

The same fabric is built as QUUX too, the CADR evolved: a card’s fpgarc says which machine its bitstream is, with --machine cadr or --machine quux (docs/fpgarc.md). QUUX runs on the Arty Z7-20 and the DE25-Nano, and the Cora Z7-07S builds the CADR alone. The CADR boots MIT’s own system software; QUUX’s system is muir-sys’s updated one.

02 / THE BOARDS

Three boards,
and what each runs.

The Arty Z7-20 and the DE25-Nano run QUUX and the CADR, and the Cora Z7-07S the CADR alone. A cell says yes where that board itself has run the thing, yes with a qualification where the thing is built into that board and nothing of it has run there yet, and no where the board does not have the thing at all. The two resource figures in each row are that board’s own place and route report for the CADR’s fabric, with the memory, the disk and both display boards in it, in that part’s own terms: lookup tables and block RAM on the Zynq boards, ALMs and M20K blocks on the DE25-Nano, and memory built out of logic is counted inside the logic figure rather than beside it. The two logic columns are different units, so their counts do not compare and the percentage is the figure that does: by Altera’s own guide for converting a Zynq-7000 design to an Agilex 5 one, an ALM is about 1.3 lookup tables. The fabric carries one video mode, 1280 by 1024 at 60 hertz, and these figures are of it; a second mode was tried once and is not built now, and its record is in the display document. What a board has built and checked but never run is on that board’s own page.

03 / THE MACHINE ITSELF

The real
machine.

The CADR was a real machine: two processor boards, a bus interface, a disk controller, a display board and an I/O board, wired together by five cables. It is worth knowing what the CADR was before looking at a drawing of it inside a chip.

05 / ABOUT

Almost nothing here
is a first-hand invention.

The CADR, the drawings, the wire lists and the microcode are MIT’s, recovered by other people’s work over decades, and the machine in the fabric is held tick for tick to muir-sim; the documents list every source the drawings were read from and what each one is.

muir-fpga is written with Claude Code, using Anthropic’s Claude Opus, Claude Fable and Claude Sonnet. The machine is written in SystemVerilog, its testbenches in C++ for Verilator, the programs beside it on the board in C, and the generators of its reference traces in Rust.

muir-fpga is muir-sim’s RTL model of the CADR and of QUUX, synthesized into the fabric of an FPGA and held to muir-sim tick for tick.
